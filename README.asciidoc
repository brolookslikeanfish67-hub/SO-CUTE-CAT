#  SO-CUTE-CAT

`SO-CUTE-CAT` is a highly polished, performance-driven fork of the legendary [Kitty terminal] 

While the original Kitty engine offers unparalleled GPU-accelerated text rendering, its strict development philosophy famously locks out heavily requested community features. `SO-CUTE-CAT` tames this beast. We add a modern user interface, richer visual flair, and deep personalization—all without sacrificing raw C and Python speed.


###  Installation & Building From Source

#### Prerequisites
Ensure you have the required compilers and development libraries installed for your platform (including Python 3, a C compiler, and OpenGL/GLFW dependencies).

#### 1. Clone the Repository
```bash
git clone https://github.com/brolookslikeanfish67-hub/SO-CUTE-CAT
cd SO-CUTE-CAT
```

#### 2. Local Development Build
Run the built-in development scripts 
```bash
python3 test.py
# Or use the developer setup wrapper
./dev.sh
```
